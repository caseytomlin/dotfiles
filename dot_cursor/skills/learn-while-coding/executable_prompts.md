# Prompt patterns (user or agent)

## Understanding

- Explain options and tradeoffs; don't implement yet.
- What are the failure modes of this approach?
- Quiz me on this change.
- What would break if we removed X?
- Walk through data flow for this path.
- Here's my hypothesis before you analyze: …

## Learning

- Give a hint, not the solution.
- Climb the hint ladder; don't jump to the answer.
- Review my approach—what's wrong or unidiomatic?
- Point me at the relevant docs concept, then let me try.
- Scaffold with TODO(human); leave the core logic to me.
- Generate a reference snippet I will rewrite from memory.
- Transfer check: if constraint X changed, what changes?

## Shipping with comprehension

- Summarize what changed and why in plain language.
- Smallest diff that meets the success criteria.
- Plan only—wait for approval before editing.
- Offer a 10-min learning exercise on what we just did (or skip).
